Git

  • git clone ссылка_с_GitHub - клонирование репозитория с GitHub на локальный компьтер.
  • git status - отображает текущее состояние рабочего каталога и области индексирования. Она помогает определить, какие изменения были внесены, какие файлы отслеживаются, а какие - нет.
  • git commit -m "название коммита" - создание коммита репозиторий Git.
  • git log - выведение списка всех коммитов.
  • git pull - сохраняет изменения из удаленного репозитория в локальный.
